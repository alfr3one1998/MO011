# مندوب — إدارة التوصيل

واجهة عربية متجاوبة لإدارة طلبات المتجر والمناديب والعهد النقدية. مبنية باستخدام React وVinext وCloudflare D1.

## الإمكانات
- إضافة الطلبات وتعيين المناديب والبحث والتصفية.
- مراحل: جديد، استلام، توصيل، تسليم. التحقق من الانتقالات والصلاحيات على الخادم.
- صلاحيات مدير ومندوب؛ يطابق حساب المندوب البريد الإلكتروني المسجل.
- روابط اتصال واتجاهات Google Maps (لا يوجد تتبع GPS حي).
- التحصيل النقدي وأجور المناديب وتسوية الطلبات المسلمة وتصدير CSV.
- وضع تجريبي منفصل في الذاكرة، لا يكتب بيانات تجريبية لقاعدة الإنتاج.
- تحديث تلقائي كل 30 ثانية، تخزين مركزي D1، المبالغ أعداد صحيحة بالهللات.

## التشغيل والنشر
يتطلب Node 22.13+ وpnpm. ثبّت الحزم باستخدام `pnpm install` ثم `pnpm dev`. للبناء استخدم `pnpm build` ولإنشاء ترحيلات المخطط `pnpm db:generate`.

الموقع يستهدف منصة Sites / Cloudflare Workers وليس GitHub Pages: الصفحات الثابتة لا تشغل قاعدة البيانات أو التفويض. المصدر محفوظ هنا، والإعدادات في `.openai/hosting.json`.

الهوية عبر تسجيل الدخول إلى ChatGPT الذي تديره Sites. لا تثق برؤوس `oai-authenticated-*` على خادم مكشوف دون بوابة Sites الموثوقة. النسخة المنشورة خاصة بالمالك. أول مستخدم مصادق يدخل موقعًا خاصًا جديدًا يُسجّل مديرًا، لذا يجب فتحه بحساب المالك قبل مشاركة الوصول. إضافة البريد إلى قائمة المناديب لا تشارك الموقع تلقائيًا؛ يجب منح الفريق الوصول عبر إعدادات Sites أيضًا.

المدفوع مسبقًا لا يدخل في العهدة النقدية. أجر المندوب منفصل عن مبلغ العميل، وتسوية الطلب تشمل استلام النقد وسداد الأجر؛ لا تنفذ تحويلات مالية فعلية. لا توجد بيانات عملاء حقيقية أو كلمات مرور في المصدر.

## التحقق
تم فحص TypeScript وبناء الإنتاج وترحيل SQLite ومنطق عدم تسوية الطلبات غير المسلمة. لم يتوفر اختبار متصفح في بيئة الإنشاء.

## Supabase integration (pending connection)

The `feat/supabase-storage` branch prepares a server-only Supabase backend, SQL schema and resumable import tool. Production remains on D1 until the target Supabase project is connected and the migration is verified. See [supabase/README.md](supabase/README.md) for activation and verification steps. Runtime secrets must never be committed.
